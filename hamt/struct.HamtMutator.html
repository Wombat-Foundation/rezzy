Struct HamtMutator

Source 
pub struct HamtMutator<K, V, KeyHash, F> { /* private fields */ }
Expand description

Carries the routing hash and lazy resolver shared by the HAMT mutation operations, so each entry point names the key/value/key-hash bounds once instead of repeating them.

The default-hash free functions (insert, remove, persist_mutations, persist_chain) construct one internally; callers using a custom routing hash build one with HamtMutator::new.
