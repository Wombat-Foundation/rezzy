Expand description

Removes a key from a HAMT via O(log S) path-copying, without rebuilding the whole tree.

Collapses any subtree that drops to a single leaf back into its parent’s datamap, cascading as needed, so the resulting tree’s structural_hash always matches what build_hamt would have produced from the same final key set.

Returns the new root and the removed value, if key was present.

This helper is only correct for trees built with build_hamt. If the tree was built with build_hamt_with_key_hash, use remove_with_key_hash with the same routing function instead.

§Errors

Returns HamtMutateError::Resolve if resolver fails to load a lazy child on the path to key.
