impl<Id: EventId, C: EventContent> EventProvider<Id, C> for LeanEventCache<Id, C>

LeanEventCache implements EventProvider so it can be passed directly to resolve_state_maps_lazy_with_diff.

Unlike a plain HashMap provider, this implementation updates the LRU generation for every access through interior mutability (Cell + RefCell), ensuring that events heavily used during lazy resolution are not prematurely evicted.
