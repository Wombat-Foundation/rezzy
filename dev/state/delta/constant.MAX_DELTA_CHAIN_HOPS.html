pub const MAX_DELTA_CHAIN_HOPS: usize = 100;
Expand description

Maximum number of delta hops before a full snapshot is inserted (default: 100, configurable: true).

Matches Synapse’s MAX_STATE_DELTA_HOPS. When a delta chain would exceed this length, compute_compacted_delta_chain_from_resolved inserts a full base snapshot instead of another delta, bounding reconstruction cost to at most this many hops.
