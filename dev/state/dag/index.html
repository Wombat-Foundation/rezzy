State DAG primitives for MSC4242 (State Res V2.2).

In rooms implementing MSC4242, state transitions form an explicit State DAG via the prev_state_events field.

This module provides the pure library-side primitives for:

  1. Traversal & Completeness: Walking prev_state_events backwards, verifying that all paths terminate at m.room.create, and discovering missing frontier gaps.
  2. Deterministic Missing Events Ordering: Sorting missing state events by (min_hops, event_id) for /get_missing_events requests.
  3. Validation: Enforcing MSC4242 validation rules (20-event fanout, non-state rejection, foreign-room checks, rejected-event cascading, create event invariants).
  4. State-from-DAG Computation: Resolving room state at any point in the State DAG.
  5. Auth Events Derivation: Calculating the authoritative auth_events from the resolved state prior to an event.
