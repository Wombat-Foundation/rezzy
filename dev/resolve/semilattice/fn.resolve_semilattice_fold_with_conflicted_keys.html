Expand description

Like resolve_semilattice_fold, but accepts a pre-derived conflicted_keys set from the caller.

This allows callers who compute conflicted_keys from a narrow, pre-widening event set (e.g. before MSC4297’s conflicted subgraph supplement) to make the debug_assert in fold_lattice_chunk load-bearing against the widened set, rather than trivially true.

When in doubt, use resolve_semilattice_fold which derives conflicted_keys internally.
