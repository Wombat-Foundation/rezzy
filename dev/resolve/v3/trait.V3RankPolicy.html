Expand description

The room-version-defined semantic ordering for concurrent V3 writers.

A production tk.nutra.cdo.12 implementation supplies one normative policy. Keeping it explicit here prevents a caller from passing a raw rank into certification after inspecting the conflict set.

The policy supplies the first three components of r(e); selection appends id(e) only after those semantic components tie.
