Expand description

Certified facts consumed by resolve_v3.

This is the boundary between ingestion/branch authentication and V3 state selection. In particular, implementations must not answer admission for merely non-rejected events: it means the event passed PDU verification and authorization against its canonical causal snapshot.

fn jointly_authorized( &self, event: &LeanEvent<Id, C, K>, selected_state: &SharedState<Id, K>, ) -> Result<bool, V3ResolveError<Id>>

Evaluate the selected writer against the immutable state assembled for this repair round. The implementation supplies the event’s certified branch-auth snapshot as required by the V3 admission rules.

For a revocation ρ targeting user u, a provider that gives the revocation cross-branch reach must require strict domination in both views; it must not infer wall-clock order:

Reach(ρ,u) ⇔ PL_θ(ρ)(sender(ρ)) > PL_θ(ρ)(u) ∧ PL_σᵢ(sender(ρ)) > PL_σᵢ(u)\operatorname{Reach}(\rho,u) \iff \operatorname{PL}{\theta(\rho)}(\operatorname{sender}(\rho)) > \operatorname{PL}{\theta(\rho)}(u) \land \operatorname{PL}{\sigma_i}(\operatorname{sender}(\rho)) > \operatorname{PL}{\sigma_i}(u)

This trait is the enforcement boundary for that room-version policy; resolve_v3 itself does not invent an answer when the provider lacks the certified facts.

§Errors

Returns V3ResolveError::IncompleteAuthContext if required branch-auth material is unavailable.
