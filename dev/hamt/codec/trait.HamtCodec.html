Expand description

Custom binary codec for HAMT leaf payloads.

This stays explicit and versioned instead of delegating persistence semantics to a generic serializer.

Required Methods§

Source

fn encode_hamt(&self, out: &mut Vec<u8>)

Encodes the value into the provided buffer.

Source

fn decode_hamt(input: &[u8], cursor: &mut usize) -> Result<Self, &'static str>

Decodes the value from the provided buffer cursor.

§Errors

Returns an error if the input buffer is too short or the encoded payload is malformed.
