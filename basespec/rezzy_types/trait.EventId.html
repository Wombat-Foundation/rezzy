Expand description

Marker trait for types that can serve as event identifiers.

Any type that is Clone + Eq + Hash + Ord + Debug + Display automatically implements this trait via the blanket implementation. Common choices are String for human-readable event IDs and integer IDs for interned storage. The Display implementation must produce the stable canonical event ID; the core crate uses that representation when computing content-addressed state hashes.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
