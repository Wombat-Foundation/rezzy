Coerces JSON values to i64 (accepts ints, uints, or string-encoded ints).

Returns None if the value cannot be interpreted as an integer. This three-way coercion handles the real-world inconsistency where some homeservers encode power levels as strings in their JSON.

FUN FACT: Room versions 1-9 actually allowed power levels to be floats and strings in the JSON, which is why rezzy has this coerce_json_to_i64 function in the first place!
