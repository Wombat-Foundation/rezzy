Expand description

Bundled inputs for Kahn’s topological sort over event power resolution.

Held as one value so the diagnostic and fallback entry points share a single bound set instead of re-declaring the same five parameters.

Fields§

§events: &'a HashMap<Id, E, S1>

Events to sort, keyed by id.

§sort_context: &'a P

Provides auth_events lookups for power-level resolution.

§create_ev: Option<&'a E>

Optional creator event used for V12+ infinite-power semantics.

§version: StateResVersion

Room version selecting the auth rules.

§pl_cache: &'a mut HashMap<Id, i64, Spl>

Scratch cache of per-event power levels, reused across sort passes.

pub fn with_cycle_diagnostics(self) -> KahnSortResult<Id>

Detailed Kahn’s Topological Sort algorithm for event power resolution.

This function performs a reverse topological sort on a set of events, placing descendants before their ancestors. It returns diagnostic details about any cycles if they are detected.

§Panics

Will panic if graph invariants are violated during topological sorting (specifically, if the in-degree map lacks an entry for a child event during the queue processing phase).

Source

pub fn sort(self) -> Vec<Id>

A simplified implementation of Kahn’s Topological Sort. Backward-compatible wrapper that falls back to standard tie-breaking on cycles.

§Panics

Will panic if graph invariants are violated (specifically, if an event returned in the cycle-breaking list of stuck nodes is missing from the input events map).
