Like compute_v2_1_conflicted_subgraph_bounded, but reuses a caller-supplied RangePrefilterReachability index instead of rebuilding one per call, and returns only the subgraph event IDs.

reachability may be built over a superset of event_context (e.g. the whole room). Restricting the forward-reachable set to event_context’s keys is equivalent to building an index over event_context itself whenever event_context is transitively closed under auth_events — every auth path between two of its nodes stays inside it — which is exactly the auth-closure shape an incremental fork walk passes here.
