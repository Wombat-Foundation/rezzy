Expand description

Like resolve_semilattice_fold, but accepts a pre-derived conflicted_keys set from the caller.

This allows callers who compute conflicted_keys from a narrow, pre-widening event set (e.g. before MSC4297’s conflicted subgraph supplement) to keep supplemental events from deciding their own state keys.

When in doubt, use resolve_semilattice_fold which derives conflicted_keys internally.
