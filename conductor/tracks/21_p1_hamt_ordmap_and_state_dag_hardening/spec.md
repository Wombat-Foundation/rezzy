## 1. Overview & Finding Traceability Matrix

Track 21 remediates 10 findings (`F-04-02`, `F-04-03`, `F-04-04`, `F-04-05`, `F-04-06`, `F-05-02`, `F-05-04`, `F-05-05`, `F-05-06`, `F-09-05`) originating from the multi-perspective architectural reviews of Track 04 ([`../04_hamt_delta_state_20260629/review.md`](../04_hamt_delta_state_20260629/review.md)), Track 05 ([`../05_lattice_v22_msc4242_20260630/review.md`](../05_lattice_v22_msc4242_20260630/review.md)), and Track 09 ([`../09_perf_interning_benchmarks_20260920/review.md`](../09_perf_interning_benchmarks_20260920/review.md)). ## 2. Functional & Architectural Remediation Requirements

### 2.1 HAMT Domain Separation, Streaming Walk Memory Bounds & `PersistentOrdMap` Hardening (`F-04-02`, `F-04-03`, `F-04-05`, `F-04-06`, `F-09-05`)
1. **Enforce Non-Empty Cross-Room Domain Separation in `StructuralHash` (`F-04-05`)**:
   - In [`src/hamt/mod.rs:192-213`](../../../src/hamt/mod.rs#L192-L213) and [`src/hamt/hash.rs`](../../../src/hamt/hash.rs), enforce that `structural_key` is a non-empty room-bound namespace (e.g., via a validated `StructuralNamespace` / `RoomId` wrapper or non-empty assertion/error) so callers cannot instantiate unkeyed HAMTs that leak cross-room subtree equality.
2. **Stream CLI HAMT & Delta Walk Outputs with Bounded RAM (`F-04-02`)**:
   - Refactor [`rezzy-cli/src/format.rs:153-465`](../../../rezzy-cli/src/format.rs#L153-L465) so `root_hashes_map` is pruned alongside `child_citations` (when an event has no remaining child citations), and provide streaming emission / bounded buffering for `roots_json`, `checkpoints`, and `unique_nodes` during `--format hamt` and `--format deltas` walks.
3. **Cold-Deserialized Snapshot Diffing & `O_DIRECT` Layer Caching (`F-04-03`)**:
   - In [`src/state/persistent_ord_map.rs:143-247`](../../../src/state/persistent_ord_map.rs#L143-L247) and [`benches/db/hamt_delta.rs:11-95`](../../../benches/db/hamt_delta.rs#L11-L95), document and guard against `Arc::ptr_eq` loss on cold-deserialized `PersistentOrdMap` snapshots (directing cold storage consumers to content-addressed `diff_hamt_nodes` or canonical node interning) and enforce/default internal HAMT layer caching ($L \ge 2$) to prevent the `O_DIRECT` cold-storage latency cliff.
4. **Rebalance Under-Full Non-Root Nodes in `PersistentOrdMap::remove` (`F-09-05`)**:
   - In [`src/state/persistent_ord_map.rs:14-26,94-98`](../../../src/state/persistent_ord_map.rs#L14-L26) (and `remove` at lines 195–237), implement sibling redistribution or merge/collapse when a non-root node drops below the minimum occupancy threshold (`MIN_OCCUPANCY = MAX_FANOUT / 3` or single-child collapse) so adversarial insert+remove churn cannot create degenerate 1-entry node chains.
5. **Clarify Persistent Storage vs. In-Memory Spec Coverage (`F-04-06`)**:
   - Update [`docs/spec_coverage.csv:1-36`](../../../docs/spec_coverage.csv#L1-L36) and [`docs/hamt_live_frontier_retention.md:7-10`](../../../docs/hamt_live_frontier_retention.md#L7-L10) to clearly distinguish in-memory state resolution from persistent HAMT delta storage and CLI walk utilities.

### 2.2 `MSC4242` State DAG Honesty, `LeanEvent` Edge De-Aliasing & Bounded Walk/Thread Execution (`F-04-04`, `F-05-02`, `F-05-04`, `F-05-05`, `F-05-06`)
1. **DAG Branch Withholding ("DAG Honesty") Detection & Reconciliation Hook (`F-05-02`)**:
   - In [`src/state/dag.rs:50-90`](../../../src/state/dag.rs#L50-L90) and [`docs/rezzy_msc4242_security_comparison.md:122-142`](../../../docs/rezzy_msc4242_security_comparison.md#L122-L142), provide a frontier-completeness / branch-withholding verification helper (checking whether concurrent known room extremities or active administrative revocation branches are omitted from a candidate `MSC4242` / `V2.1.1` subgraph) and add an explicit branch-withholding demonstration test in `tests/unit/test_state_dag.rs` linking `src/state/dag.rs` to frontier reconciliation (`rezzy-recon`).
2. **De-Alias `prev_state_events` from `auth_events` on `LeanEvent` (`F-05-04`)**:
   - In [`src/basespec/rezzy_types.rs:1609-1614`](../../../src/basespec/rezzy_types.rs#L1609-L1614) and [`src/auth/mod.rs:690-704`](../../../src/auth/mod.rs#L690-L704), separate `prev_state_events` from `auth_events` on `LeanEvent` (via a dedicated field or typed `AuthOrStateEdges` representation) so `event.auth_events()` never silently returns `MSC4242` `prev_state_events`.
3. **Enforce Mandatory `max_steps` in `StateDagWalkOptions` & Parallel Thresholds in `resolve_semilattice_fold` (`F-05-05`)**:
   - In [`src/state/dag.rs:76-90`](../../../src/state/dag.rs#L76-L90), replace `max_steps: Option<usize>` (or clamp `None` to a hard maximum ceiling `MAX_DAG_WALK_STEPS`) so untrusted federation walks can never run with an unbounded step budget.
   - In [`src/resolve/semilattice.rs:33-37`](../../../src/resolve/semilattice.rs#L33-L37) (and lines 240–250), eliminate the mainline head panic risk with a defensive fallback and add a minimum event-count threshold (`MIN_PARALLEL_EVENTS = 256`) before spawning OS threads via `std::thread::scope`.
4. **Enforce Cross-Room `RoomId` & `EventVerifier` Plumbing Across State-At, HAMT & State DAG Walks (`F-04-04`, `F-05-06`)**:
   - In [`rezzy-cli/src/format.rs:306-384`](../../../rezzy-cli/src/format.rs#L306-L384), [`src/state/at.rs:104-220`](../../../src/state/at.rs#L104-L220), [`src/state/dag.rs:107-113`](../../../src/state/dag.rs#L107-L113), and [`src/auth/mod.rs:2100-2130`](../../../src/auth/mod.rs#L2100-L2130), thread mandatory `RoomId` validation (and optional/configurable `EventVerifier`) so `ReferencedForeignRoom` and `ForeignRoomEvent` (`MSC4307` Rule 2.5) are enforced during state-at reconstruction, live HAMT walks, and `validate_state_dag_ancestors`.

## 3. Public-Safety & Consensus Invariants

1. **Cross-Room Cryptographic & Auth Isolation (`F-04-04`, `F-04-05`, `F-05-06`)**: Every HAMT `StructuralHash` MUST be domain-separated by a non-empty room key, and every `validate_state_dag_ancestors` / `compute_state_at` walk MUST reject foreign-room event citations (`MSC4307` Rule 2.5).
2. **Type-Safe `MSC4242` Edge Separation (`F-05-04`)**: `MSC4242` `prev_state_events` MUST NEVER be aliased into classic `auth_events` slices.
3. **Bounded Traversal, Threading & Tree Density (`F-04-02`, `F-05-05`, `F-09-05`)**: State DAG walks MUST enforce a finite step bound, `resolve_semilattice_fold` MUST NOT spawn OS threads for small conflicted sets, and `PersistentOrdMap::remove` MUST maintain bounded tree height under arbitrary insert/remove churn.
