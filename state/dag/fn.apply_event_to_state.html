Expand description

Applies an event’s own state to state in place, yielding the state after it.

If event is an accepted state event, records (event.event_type, event.state_key) -> event.event_id; otherwise it is a no-op. Compose with compute_state_before_from_dag to obtain the state after an event without a second DAG traversal.
