Expand description

Reconstruct the full state map by looking up a checkpoint by event ID.

This is a convenience wrapper around reconstruct_state_at that finds the checkpoint index for the given event_id and reconstructs the state.

Returns None if the event ID is not found in the checkpoint chain or the chain is broken.
