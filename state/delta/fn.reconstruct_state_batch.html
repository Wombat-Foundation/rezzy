pub fn reconstruct_state_batch<Id: EventId>(
    checkpoints: &[CompactedCheckpoint<Id>],
    target_indices: &[usize],

Expand description

Reconstructs the full state map at multiple checkpoint indices in one pass.

Instead of calling reconstruct_state_at N times (which re-walks shared ancestors), this function finds the nearest snapshot before the earliest target and walks forward once, capturing state at each requested index.

Complexity: O(span) where span = max(targets) - snapshot_base, versus O(N * span) for N individual calls.

§Arguments

  • checkpoints — a slice of CompactedCheckpoints in chronological order.
  • target_indices — the indices to reconstruct (duplicates and out-of-bounds are silently ignored).

§Returns

A persistent ordered map keyed by the requested indices. Missing entries indicate broken chains or out-of-bounds indices.

§Panics

Panics if an internal index increment overflows usize (should never happen with valid checkpoint data).
