Expand description

Computes a deterministic 256-bit LtHash fingerprint of a state map, returned as a 32-byte array.

This is a convenience wrapper around LtHash::from_state. Each (event_type, state_key, event_id) entry is expanded via SHAKE256 to a 2048-byte seed, and the state hash is the wrapping addition of all seeds — making it order-independent and incrementally updatable.
