pub type FastSharedState = SharedState<Arc<str>, InternedKey>;
Expand description

The fast SharedState configuration: Arc<str> event ids and InternedKey state keys, so every path-copy clone is a refcount bump instead of a string allocation.

“Interned” here means Arc-backed, not canonical: InternedKey::new on two equal strings allocates two buffers. Sharing comes from the ingest helper, which dedups within the batch it is given (see intern_events); it is not a global intern table.

Measured against the String/String default (state_key_repr and the matrix in state/interned_key benches): inserts into a forked state take ~0.55-0.66x the time, and full resolution ~0.56x on linear rooms and ~0.62-0.68x on conflict-heavy rooms. Lookup and diff are unchanged. Ordering is still plain string order, so this is valid for live Matrix state (unlike a frozen-vocabulary u32 interner).

Build the inputs with intern_events, which allocates each event id and state key once and shares it everywhere.
