Enum StateUpdate 

Source 
pub enum StateUpdate<'b, Id, K = String> {
    New {
        state: SharedState<Id, K>,
        hash: &'b LtHash,
    },
    Unchanged {
        parent_event_id: &'b Id,
        hash: &'b LtHash,
    },
}
Expand description

Represents an optimization-friendly state update yielded during topological streaming.

Manual Clone/Debug/PartialEq/Eq impls (rather than #[derive]) because SharedState<Id, K> (an imbl::OrdMap) requires K: Ord structurally, which #[derive]’s naive per-field bound inference does not add automatically.

Variants§

§

New

The state has been newly resolved, or modified by a state-changing event.

Fields

§state: SharedState<Id, K>

The resolved state map at this target.

§hash: &'b LtHash

The incrementally maintained LtHash digest for this state, borrowed from the pipeline’s owned state. Zero-copy: callers that only compare, look up, or digest can borrow; only callers that need to retain the hash (e.g. across a thread channel) should copy it.

§

Unchanged

The state at this event is completely unchanged from its parent’s state. Consumers can reuse the parent’s state directly, skipping compression and O(N) traversals.

§Important

The referenced parent_event_id may not have been yielded as a target. Callers must have the parent’s state available from a prior persistence pass (e.g., a full-rebuild pipeline). Use StateUpdate::into_state with a closure that can look up any ancestor’s state, not just previously-yielded targets.

Fields

§parent_event_id: &'b Id

The event ID of the single parent event from which this state is inherited.

§hash: &'b LtHash

The LtHash digest of the parent state, borrowed from the pipeline’s owned state (zero-copy; see StateUpdate::New).

Source

pub fn lattice(&self) -> &LtHash

Borrows the carried LtHash lattice (the 2 KiB homomorphic accumulator) — zero-copy. The 32-byte cryptographic hash of it is StateUpdate::digest.

Source

pub fn digest(&self) -> [u8; 32]

Computes the 32-byte MSC4500 §6 digest of the carried LtHash lattice.

Cheap (BLAKE2b over the 2 KiB lattice) and collision-resistant to 256 bits; useful as a compact dedup/identity key without copying the full lattice.
