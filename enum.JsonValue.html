Enum JsonValue

pub enum JsonValue {
    Null,
    Bool(bool),
    Number(Number),
    String(String),
    Array(Vec<Value>),
    Object(BTreeMap<String, Value>),
}
Expand description

An owned JSON value.

Default is Null, so unwrap_or_default() on a failed parse silently yields Null; match on the Result when the distinction matters.
